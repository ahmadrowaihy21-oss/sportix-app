# SPORTIX ACADEMY — Football Academy Portfolio

This is the isolated GitHub source branch for the Arabic SPORTIX ACADEMY portfolio.

Target custom domain: **acpf.sportixpartners.com**.

## Deployment status
The HTML files have been staged on this branch. The final production deployment is not completed until:
1. The approved logo and cover-image binary assets are uploaded to `assets/`.
2. The eight-page PDF is uploaded to `documents/`.
3. GitHub Pages or a Git-connected static host is configured to deploy this branch.
4. A CNAME record for `acpf` is added in the authoritative DNS zone for `sportixpartners.com`.
5. TLS and live pages are verified.

The existing `main` branch has not been changed.

## Required files
- `index.html`
- `brochure.html`
- `assets/sportix-academy-logo.webp`
- `assets/academy-cover.webp`
- `documents/SPORTIX_ACADEMY_FOOTBALL_PORTFOLIO_AR.pdf`
