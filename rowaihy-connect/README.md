# ROWAIHY CONNECT — مركز اختبار المشاريع
نسخة أولى محلية لاختبار أنظمة مشاريعك على Windows. واجهة عربية RTL بهوية داكنة ولمسات نعناعية، مع قاعدة بيانات SQLite على جهازك.

## ماذا تعمل هذه النسخة؟
- حفظ مشاريع وروابط بيئات الاختبار وإعداد فحوصات مستقلة لكل مشروع.
- تشغيل فحوصات HTTP وAPI فعلية: GET وHEAD، رمز الاستجابة، نص مطلوب، قيمة JSON، ووقت الاستجابة.
- تشغيل مشروعين بالتوازي، قائمة انتظار، منع تكرار تشغيل المشروع نفسه، وإلغاء التشغيل.
- حفظ نسخة إعدادات المشروع وقت كل تشغيل، ونتائج كل فحص، وتقارير HTML قابلة للتنزيل.
- عرض أحدث 200 تشغيل؛ تبقى التشغيلات الأقدم محفوظة في قاعدة البيانات.
- تصدير واستيراد تعريفات المشاريع بصيغة JSON.
- فحص ذاتي للتطبيق المحلي نفسه دون حسابات خارجية.

هذه النسخة لا تشغّل تفاعلات المتصفح أو اختبارات تسجيل الدخول/OAuth أو وكلاء الذكاء الاصطناعي، ولا تربط حساباتك الخارجية. لا تعرض نتائج وهمية ولا تعتبر استجابة HTTP ناجحة دليلًا على اكتمال نظامك. الخطوة التالية هي إضافة سيناريوهات المتصفح لمشاريع تحددها.

## التشغيل على Windows
1. ثبّت **Node.js 24 LTS أو أحدث** من https://nodejs.org إذا لم يكن موجودًا.
2. فك ضغط المشروع في مجلد تملكه، مثل Documents. افتح مجلد `rowaihy-connect`.
3. افتح **Start-Rowaihy.cmd** بالنقر المزدوج. لا تحتاج صلاحية Administrator أو Docker أو npm install.
4. بعد ظهور رابط التشغيل في النافذة، افتح **http://127.0.0.1:4310**.
5. اختر «إضافة فحص ذاتي» للتأكد من جاهزية الخادم، ثم أضف رابط مشروعك وفحوصاته.

أبق نافذة التشغيل مفتوحة. للإيقاف اضغط **Ctrl+C**. إن ظهر خطأ `EADDRINUSE` فالمنفذ مستخدم؛ أغلق النسخة السابقة، أو شغّل من PowerShell:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Rowaihy.ps1 -Port 4311
```
التغيير في ExecutionPolicy خاص بعملية التشغيل هذه فقط، ولا يغير سياسة Windows الدائمة.

## مثال اختبار مشروع
رابط المشروع: `http://localhost:3000/`
- الصفحة الرئيسية: GET `/`، الرمز المتوقع 200.
- صحة API: GET `/api/health`، الرمز 200، مسار JSON `ok`، القيمة `true`.
- صفحة محمية: GET `/admin`، الرمز المتوقع 401 إذا كان هذا سلوك تطبيقك.

القيمة المتوقعة لـ JSON يجب أن تكون JSON صحيحًا: `true` للمنطقي، `200` للرقم، و`"ok"` للنص. استخدم `$` لمقارنة الجذر، أو `data.ready` لمسار متداخل. المساواة تقارن نوع البيانات أيضًا. المسارات يجب أن تبقى ضمن origin المشروع؛ لا تُتبع التحويلات تلقائيًا. GET وHEAD قد يغيران البيانات إذا صُممت واجهة هدفك بطريقة غير سليمة، لذلك استخدم بيئات الاختبار التي تملكها.

## حدود التشغيل الحالية
- واجهة محلية فقط على 127.0.0.1. ليست خدمة عملاء منشورة أو خادمًا مكشوفًا للإنترنت.
- لا يفتح البرنامج منافذ الراوتر أو Windows Firewall، ولا يثبت خدمات أو مهام تشغيل تلقائي.
- لا تضف كلمات مرور أو رموز وصول إلى روابط الفحوصات. لا يوجد مخزن أسرار في هذه النسخة.
- 30 فحصًا لكل مشروع، مهلة من 100 إلى 30000 ms لكل فحص، وحد استجابة 512 KiB.
- استيراد تعريفات حتى 50 مشروعًا وبحجم 256 KiB للطلب. الاستيراد يضيف نسخًا ولا يحذف الموجود.
- الإلغاء يوقف الفحوصات المتبقية ويحفظ النتائج المكتملة. التشغيل المتوقف بسبب إغلاق الجهاز يُعلّم «توقف قبل الاكتمال» عند بدء التطبيق.
- لا يوجد جدول تشغيل تلقائي أو وكيل دائم بعد إغلاق الجهاز.
- النتيجة مبنية على شروطك فقط؛ هذه ليست شهادة أمان أو اختبارًا شاملًا للوظائف.

## البيانات والنسخ الاحتياطي
تُحفظ البيانات في `data/rowaihy.sqlite` بجوار التطبيق، وتُستبعد من Git.
- تصدير المشاريع من الواجهة ينقل التعريفات فقط، لا سجل التشغيل.
- للنسخة الكاملة: أوقف التطبيق، ثم انسخ مجلد `data` كاملًا. للاستعادة أوقفه وأعد المجلد قبل التشغيل.
- ملفات التقارير قد تحتوي أسماء مشاريعك وقيم JSON التي اختبرتها؛ شاركها حسب حاجتك.

## التحقق
```powershell
npm test
```
أو افتح `Test-Rowaihy.cmd`. الاختبارات تستخدم قواعد مؤقتة وخوادم محلية، ولا تتصل بحساباتك أو مواقع عملائك.
اختبارات CI معدة لـ Windows وLinux مع Node.js 24. حالة النجاح الفعلية هي نتيجة GitHub Actions، وليست مجرد وجود ملف الاختبارات.

## للمطور
لا توجد حزم تشغيل خارجية. `node:sqlite` يتطلب Node.js 24 أو أحدث وقد يعرض تحذيرًا تجريبيًا بحسب إصدار Node. هذا لا يعني فشل التشغيل.
- `src/server.mjs`: واجهة HTTP المحلية وحماية Host/Origin.
- `src/validation.mjs`: التحقق من المشاريع وعزل طلبات كل مشروع في أصله.
- `src/runner.mjs`: تنفيذ الفحوصات والطابور.
- `src/store.mjs`: SQLite وسجل التشغيل.
- `public/`: الواجهة.
- `test/`: اختبارات فعلية دون بيانات إنتاجية.

حفظ هذا المشروع في فرع تطوير مستقل ضمن مستودعك الحالي لا ينقله إلى أي موقع إنتاجي. لا تدمج الفرع فوق تطبيق SPORTIX الأساسي؛ افتح المجلد المحلي المخصص أو انقله إلى مستودع مستقل لاحقًا.
